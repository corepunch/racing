# Overcast Environment

- Asset: Overcast Soil (Pure Sky), converted to a 2K, 8-bit sRGB PNG.
- Original photography: Sergej Majboroda. Sky edits: Jarod Guest.

The source panorama was converted offline using Blender's AgX view transform
with the Medium High Contrast look at zero exposure, exported as an 8-bit RGB
PNG. The original HDR is not bundled.
The same LDR image supplies the background and environment lighting.

HDR rendering, exposure adaptation, bloom, and motion blur are explicitly
disabled. Muted material colors, cool lighting, and blue-gray distance fog
provide the atmosphere without an HDR post-processing pipeline.
